# COVID-19 Global Analysis Dashboard

An interactive **Power BI dashboard** created to analyze and visualize global COVID-19 statistics.

## 📊 Project Overview

This project provides a visual analysis of COVID-19 data using Power BI. The dashboard presents important COVID-19 statistics through interactive charts, cards, and visualizations, making it easier to understand the global impact of the pandemic.

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Data Visualization**
- **Data Cleaning & Transformation**

## 📈 Dashboard Features

- Total COVID-19 cases
- Total deaths
- Total recovered cases
- Active cases
- Recovery rate
- Case fatality rate
- Country-wise analysis
- Interactive charts and visualizations
- KPI cards for important statistics
- Filters and slicers for interactive analysis

## 🔍 Key Analysis

The dashboard helps analyze:

- The overall global impact of COVID-19
- Differences in COVID-19 cases between countries
- Death and recovery patterns
- Active cases across different regions
- Important COVID-19 performance indicators

## 🧹 Data Preparation

The data was prepared using **Power Query**, including:

- Removing unnecessary data
- Handling missing values
- Correcting data types
- Transforming columns
- Creating calculated metrics
